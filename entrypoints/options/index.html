Matchblatt-Foto für click-tt

Die Erweiterung liest ein Foto des ausgefüllten Matchblatts und trägt Aufstellung und Satzresultate in click-tt ein. Die Auswertung des Fotos übernimmt die KI Claude von Anthropic mit deinem eigenen API-Key.

Erstellen unter platform.claude.com. Der Key wird nur lokal in diesem Browser gespeichert.

Datenschutz

Das Foto und die Spielernamen der beiden Mannschaften aus click-tt werden direkt von deinem Browser an die Claude-API von Anthropic gesendet, um das Matchblatt auszuwerten. Es gibt keinen Server dieser Erweiterung, keine Analyse und kein Tracking. Zuordnungen von Namen auf dem Matchblatt zu click-tt-Spielern werden nur lokal gespeichert.
